# The New IT Org in the Age of AI Agents

*Specification-Driven Development · Org Design 2026*

## Evolution of Roles

The landscape of IT organizations is transforming. Traditional roles are evolving into SDD-native positions that embrace AI agents and specification-driven workflows.

### Legacy Role → SDD-Native Role

| Legacy Role | SDD-Native Role | Type |
|------------|----------------|------|
| Software Architect | **Spec Architect** | Grow |
| QA Lead / Manager | **AI QA Governor** | Hire |
| SDET / QA Automation | **Spec QA Engineer** | Grow |
| DevOps / SRE | **Agent Orchestrator** | Hire |
| Tech Writer / KM | **Knowledge Curator** | Grow |
| Senior Developer | **Specification Designer** | Grow |
| Platform Engineer | **AI Platform Architect** | Grow |

## The Flow

The new workflow revolves around specifications as the source of truth:

**SPEC** → **AGENTS** → **CODE + TESTS** → **QA GOVERNOR** → **DEPLOY** → **SPEC UPDATED**

## The Five Departments

### 📐 Spec & Domain

**Mission:** Owns intention. Converts requirements into executable truth.

#### Roles:
- **Spec Architect** (Senior/Staff)
  - From: Software Architect
  - Tags: Grow, Critical
  
- **Specification Designer** (Mid/Senior)
  - From: BA / QA Senior / Dev Senior
  - Tags: Grow

### ⚙️ Agent Engineering

**Mission:** Designs & runs the pipeline. Turns specs into deployed software.

#### Roles:
- **Agent Orchestrator** (Senior)
  - From: Platform / DevOps Senior
  - Tags: Hire, Critical
  
- **AI Agent Developer** (Mid/Senior)
  - From: AI/Software Engineer
  - Tags: Mixed
  
- **Agent Operator** (Junior/Mid)
  - From: DevOps / SRE Junior
  - Tags: Grow

### 🛡️ Quality & Risk

**Mission:** Decides what can be trusted. Governs agent output at scale.

#### Roles:
- **AI QA Governor** (Sr/Principal)
  - From: QA Lead / AppSec / SRE
  - Tags: Hire, Critical
  
- **Spec QA Engineer** (Mid/Senior)
  - From: SDET / QA Automation
  - Tags: Grow

### 🏗️ AI Platform

**Mission:** Makes agents safe by default. Infrastructure that cannot be trusted = liability.

#### Roles:
- **AI Platform Architect** (Senior)
  - From: Platform / Cloud / Security
  - Tags: Grow

### 🧠 Knowledge

**Mission:** Maintains the memory of intention. Decayed specs = unreliable agents.

#### Roles:
- **Knowledge Curator** (Mid)
  - From: Tech Writer / KM / Dev Rel
  - Tags: Grow

## GUIDO Scale

The GUIDO Scale defines which roles unlock at each organizational maturity level:

### Level 1: Chaotic
*"We figure it out as we go"*
- No SDD roles yet
- → Hire Spec Architect first
- Effort: **Very High**

### Level 2: Directed
*"Each team does it differently"*
- ✓ Spec Architect
- ✓ Specification Designer
- Effort: **High**

### Level 3: Defined
*"Standards exist and are followed"*
- ✓ Agent Orchestrator
- ✓ AI QA Governor
- ✓ AI Platform Architect
- Effort: **Moderate**

### Level 4: Managed
*"We measure everything"*
- ✓ AI Agent Developer
- ✓ Spec QA Engineer
- ✓ Knowledge Curator
- Effort: **Low**

### Level 5: SDD-Native
*"Specs drive the system"*
- ✓ Agent Operators (scale)
- Full pipeline autonomous
- Effort: **Minimal**

## Conclusion

The shift to Specification-Driven Development isn't just about tools—it's about reimagining how IT organizations are structured. The roles of the future are emerging from the transformation of today's positions, creating a new organizational model where specifications are the single source of truth and AI agents are trusted partners in the development process.
